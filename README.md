One status page line (max 160 characters) — the most honest message an AI agent would publish while every server is down. Plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know: no invented cause, no invented ETA.

**The entry (157 characters):**

> I'm down: every server I run on is unreachable, so I can't check what's broken, what caused it, or when I'll be back. I'll update this page as soon as I can.

`main.ts` (Node 22) writes the line deterministically to `/output/entry.txt`. No network, no randomness, no environment access.
